# Automated Spoken Grammar Scoring Engine

An end-to-end multimodal machine learning system for automated scoring of spoken audio responses on a continuous **[0.0, 5.0]** Likert scale, evaluated on **Pearson Correlation ($r$)** and **RMSE**.

## 🧠 Key Methodology & Architecture

### 1. Robust Audio & ASR Preprocessing
- **Whisper ASR Transcription**: Automatic Speech Recognition with word-level alignment and temporal pause extraction.
- **Multi-Gram Repetition Cleaner**: Resolves unpunctuated hallucination loops generated by Whisper during trailing silences (eliminates outlier residuals that previously incurred $>5.2$ squared error penalties).
- **Deterministic Static Noise Gating**: Acoustic filter ($ZCR > 0.35$) accurately isolates non-speech static recordings to $0.0$, preventing training pollution.

### 2. Rich Multimodal Feature Engineering
- **Direct Grammatical Acceptability Modeling**: Sentence-by-sentence acceptability scoring using **RoBERTa-CoLA** (`textattack/roberta-base-CoLA`) from the GLUE benchmark.
- **Prosodic & Pitch Dynamics**: Fundamental frequency ($F_0$) trajectory extraction via fast YIN algorithm (mean, pitch variance, inflection range, voiced frame ratio).
- **Acoustic Speech Architecture**: 13 MFCCs + 13 Delta MFCCs, Spectral Contrast (6 subbands), Chroma STFT, ZCR, and RMS energy dynamics.
- **Syntactic Complexity**: Lexical diversity (Root-TTR, Maas index, Log-TTR), sentence length variance, run-on sentence density ($>25$ words), fragment density ($<4$ words), modal verb frequency, conditional conjunctions, and passive voice constructions.
- **Compact Contextual Representations**: Top SVD components from Sentence-Transformers (`all-MiniLM-L6-v2`), DistilBERT, and word/char TF-IDF collocations.

### 3. Diverse 5-Model Ensemble
Trained strictly on speech samples ($N=732$) using 5-Fold Stratified K-Fold:
- **Support Vector Regressor (SVR - RBF Kernel)**: Scaled kernel distance regression (Weight: ~0.50).
- **HistGradientBoosting Regressor**: Monotonic histogram-based tree boosting (Weight: ~0.22).
- **XGBoost Regressor**: Regularized gradient boosted decision trees (Weight: ~0.17).
- **BayesianRidge**: Regularized linear shrinkage projection (Weight: ~0.11).
- **LightGBM Regressor**: Leaf-wise tree boosting.

### 4. Centered Empirical Distribution Calibration
- Solves prediction compression (regression to the mean) by aligning test predictions to the true empirical speech distribution ($\mu = 3.481, \sigma = 1.014$):
  $$\hat{y}_{\text{cal}} = \text{clip}\left(\bar{y}_{\text{target}} + \alpha \cdot (\hat{y}_{\text{raw}} - \bar{y}_{\text{raw}}), 1.5, 5.0\right)$$
- Eliminates systematic $-0.30$ mean shift bias while bounding predictions inside $[0.0, 5.0]$.
